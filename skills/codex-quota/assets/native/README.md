# AI 额度

一个免费的原生 macOS 菜单栏工具，集中查看 Codex、Grok Bot、Manus、Cue 和 Muse 的额度。查询、自动刷新和本地文件读取都使用确定性程序，不调用 AI 模型，不发起 AI 对话。

菜单栏仍只显示一个剩余百分比，初始默认 Codex。可在「设置 → 菜单栏默认额度」或选中应用下方的操作栏中更改默认来源，选择会保存在本机。点击图标只切换详情，不改变默认来源。

应用区使用横排的本机应用图标，图标下显示剩余百分比和简短重置时间；点击图标切换详情。应用超过一排时可横向滚动查看。当前应用的操作集中在图标区下方，额度详情单独滚动。界面使用 macOS 原生图标、表单、进度条、按钮和系统弹窗，跟随深浅外观及强调色。周期百分比与额外余额分别展示；余额不参与菜单栏百分比。所有重置时刻、到期时刻与公告时间按北京时间显示，只有日期的数据保留日期精度。

总览使用 44 pt 应用图标，不显示名称和更多按钮；悬停或辅助功能仍能读出名称，选中的详情标题也包含应用名。图标区下方的原生文字操作栏只作用于当前选中的应用，提供设为菜单栏默认、打开应用、连接登录或移除扩展；点击图标仅切换详情，不改变默认。切换应用时详情从顶部开始。刷新过程中显示进度并禁用重复刷新。使用上次成功数据时，概览百分比旁显示警告标记，详情说明连接错误；恢复按钮统一使用「授权」「登录」「重试」，连接期间不可重复点击。

图标下显示额度重置时间，最近同步时间移到悬停提示和详情。多个主要周期同时存在时在悬停提示与详情标明对应周期，不把所有额度视为同时重置；来源没有提供时间时明确显示未知。顶部预告栏已移除，预告和历史动态保留在 Codex 详情的折叠区。

## 来源与连接

| 来源 | 连接方式 | 展示内容 |
| --- | --- | --- |
| Codex | 复用本机 Codex 桌面应用或 CLI 登录 | 各额度分组与周期、自动重置时间、可用重置机会及到期时间 |
| Grok Bot | 原应用先登录，必要时点击「授权」允许读取对应 Keychain 项 | 周期额度；接口提供时另列按量剩余上限 |
| Manus | 原应用先登录，必要时点击「授权」允许读取对应 Keychain 项 | 月度积分、单列的每日或每周刷新积分，以及免费、额外购买和活动余额 |
| Cue | 原应用先登录，必要时点击「授权」允许读取对应 Keychain 项 | 每周积分，含预留用量；另列额外购买余额 |
| Muse | 点击「登录 Muse」，在工具自己的网页登录窗口连接 `https://muse.ai` | 每周用量与额外词元余额 |

后台 Keychain 查询不弹授权窗口。凭据只在程序内部用于对应服务的固定 HTTPS 地址，不写入额度结果或错误提示。Muse 使用本工具独立的 WebKit 登录会话，不读取 Meta 私有 Keychain 分组；网页登录 token 能否访问真实 hatch 额度接口，仍需用户完成登录后验证。已实现适配器和脱敏样本测试，不代表五个来源都已通过真实账号验证。

未连接时先选择对应图标，在下方连接状态中使用「登录」「授权」或「重试」；提示区分登录、权限和网络问题。Muse 登录窗口中的「验证登录并读取额度」会先检查网页登录，再读取真实额度；只有两步都成功才关闭窗口，失败会留在窗口中说明原因。网页登录复查未发新令牌时，仅复用同一账号和会话此前取得的内存令牌；未知或失效身份会清除它。

Manus 的刷新积分与月度积分是不同池；刷新积分单列，不拉低月度摘要。额外购买、免费和活动余额也单列。来源未提供分母时只显示余额，百分比保持未知。

各服务独立刷新，Codex 每分钟一次，其他内置来源通常每五分钟一次；失败后逐步延长重试间隔，最长一小时。一个来源失败不影响其他来源，休眠或退出时停止查询，唤醒后恢复。缺失数据保持未知，不当作零。失败时只保留确认属于同一账号的上次成功数据并标记过期；账号切换、退出登录或无法确认身份时清空旧账号数据。

## 使用与扩展

需要 macOS 13 或更新版本。双击 `dist/Codex额度.app` 或已安装的 `~/Applications/Codex额度.app`，点击菜单栏百分比打开面板。展示名为「AI 额度」；插件 slug `codex-quota`、应用文件名、可执行文件和 bundle ID 保持兼容。

「设置 → 显示的应用」可启用或隐藏内置来源；「添加应用」可导入本地额度 JSON 文件。文件提供稳定应用标识、周期或余额、重置信息和必填的 `observedAt`；导入后每分钟重新读取，不执行外部脚本。缺失指标保持未知，文件不得含 token、cookie、账号身份或其他凭据。格式与限制见 [扩展说明](docs/quota-provider-extension.md) 和 [示例文件](examples/quota-provider.json)。

Codex 的每次可用机会旁保留「重置」按钮：点击即消耗所选机会并重置额度，无额外确认框。查询、安装和预览不会使用重置机会。结果不确定时保留原请求标识并提供「重试上次重置」，避免重复消耗；此时其他重置操作保持禁用。不要删除待确认记录来绕过保护。

## 本地构建与只读诊断

先安装 Xcode Command Line Tools 和 Python 3，再在项目目录执行：

```sh
xcode-select --install
python3 scripts/local-signing.py setup
bash scripts/build-app.sh
open dist/Codex额度.app
```

构建脚本只生成并签名 `dist/Codex额度.app`，不会启动或安装应用。产物用于个人 Mac 本地运行，使用这台 Mac 登录钥匙串中的固定本地签名身份，不需要购买开发者会员，未做 Developer ID 签名或 Apple 公证。

`setup` 只需初始化一次，之后会核验并复用原证书。证书只用于代码签名，私钥不可导出且仅授权系统 `codesign` 使用；公开证书和身份指纹保存在 `~/Library/Application Support/CodexQuota/Signing`。构建时身份缺失或失效会停止，不会自动换证书或退回临时签名。不要删除签名记录或钥匙串中的原证书和私钥。

从旧临时签名迁移后，首次读取 Grok Bot、Manus、Cue 的登录项可能还需要各授权一次「始终允许」。后续更新复用同一签名身份和 bundle ID，避免因每次构建身份变化而反复要求密码。后台查询仍不会弹出密码窗口；原应用更换登录项或钥匙串被锁定时可能需要重新授权。

```sh
# 兼容原来的 Codex 单独查询
dist/Codex额度.app/Contents/MacOS/CodexQuota --diagnose
# 查询五个内置来源，各自返回额度或安全状态
dist/Codex额度.app/Contents/MacOS/CodexQuota --diagnose-all
# 只查询公开重置公告
dist/Codex额度.app/Contents/MacOS/CodexQuota --diagnose-announcements
swift test
```

插件附带的 `skills/codex-quota/scripts/quota.sh` 提供 `check`、`signing-setup`、`build`、`query`、`query-all`、`install`、`open`。首次构建前显式运行 `signing-setup` 初始化本机固定签名，已有身份会核验并复用；普通构建不自动初始化。`query` 保留 Codex JSON 兼容输出，`query-all` 使用 `--diagnose-all`。helper 可编译缓存应用，但不会替换现有安装或正在运行的应用，也没有重置命令。升级已有安装由独立部署步骤处理。

## Codex 与公开公告

Codex 通过本机 `codex app-server` 查询账号额度和执行已授权的重置，不需要 API key。支持新版 `Resources/codex-cli` 和旧版 `Resources/codex` 布局；桌面应用更新后下次刷新会重新定位。可用重置机会的到期是机会失效时间，不是会员到期或额度自动刷新时间；明细条数不用于推算可用总数。

「重置动态」使用 [Codex Resets 免费公开 API](https://codex-resets.com/api/docs) 同步 Tibo 公告，无需 X 登录，每十分钟检查一次，手动检查最多每分钟一次。预告与历史保留最近十条，在 Codex 详情中展开查看原帖、原文与可解析的重置时间。第三方转录可能延迟或遗漏；「原文称已完成」不表示当前账号已到账，公告不会触发账号重置或改变额度。

公开公告失败时保留上次内容，缓存位于 `~/Library/Caches/CodexQuota/announcements-v1.json`。不携带账号信息，不调用付费翻译或 AI 接口。无法可靠解析时区或时间的预告只显示「时间未明确」，不把公告发布时间当作重置时间。
