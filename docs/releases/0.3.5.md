# AI 额度 0.3.5

本次首次公开发布整合了此前本地版本的多应用额度功能与最新界面优化。

## 新功能

- **一个面板查看五款应用**：Codex、Grok Bot、Manus、Cue 和 Muse 的额度独立刷新。
- **菜单栏默认来源可切换**：仍只显示一个百分比，选择会保存；查看其他应用不会改掉默认项。
- **本地扩展入口**：通过 JSON 文件接入其他 AI 软件的额度，周期、余额和重置时间分别展示。
- **Codex 重置与动态**：保留重置机会按钮，公开预告和历史动态收纳到可展开的详情区域。

## 界面优化

- 应用图标横排，尺寸定为 **44 pt**。
- 删除总览中的名称和更多按钮，将操作集中到当前应用下方。
- 直接显示北京时间的额度重置摘要；来源未提供时间时明确说明。
- 增加刷新和连接进度、旧数据警示、错误重试及清晰的详情标题。
- 使用 macOS 原生组件，跟随系统深浅外观。

## 兼容与修复

- 兼容新版 Codex 安装布局。
- 修复 Grok Bot 登录读取，完善 Muse 登录与额度验证。
- 复用固定本机签名和安装路径，减少更新导致的重复密码授权。首次连接或系统登录状态变化时仍可能需要本人授权。

## 安装与数据

需要 macOS 13+、Swift 5.9+（Xcode Command Line Tools）和 Python 3。按仓库 README 在自己的 Mac 上构建；下载附件提供源码，不是经过 Apple 公证的应用安装包。

本仓库没有附带开发者的账户、个人邮箱、真实额度截图、本机诊断记录或签名材料。测试数据采用虚构样例。额度查询和自动刷新不调用 AI 模型，也不会自动消费 Codex 重置机会。

原生组件的布局已经过本地渲染检查；真实鼠标、键盘和 VoiceOver 流程未完成自动化验收。

## 发布验证

- 对最终公开源码执行 162 项 Swift 测试，全部通过。
- 本地签名脚本的 19 项模拟测试全部通过。
- 发布前检查文件清单、作者信息和测试样例；未包含本机账户数据或签名材料。
- 未在另一台新 Mac 上验证首次签名和全部账户连接。
